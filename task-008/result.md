# Project Tree-1777369476

Este proyecto es una aplicación web moderna construida con tecnologías frontend estándar.

## Instalación

Para instalar las dependencias del proyecto, ejecuta:

```bash
npm install
```

## Desarrollo

Para iniciar el servidor de desarrollo local:

```bash
npm run dev
```

Esto iniciará un servidor en `http://localhost:3000` (o el puerto configurado).

## Construcción

Para generar una versión de producción optimizada:

```bash
npm run build
```

Los archivos resultantes se guardarán en la carpeta `dist/`.

## Deployment

Este proyecto puede desplegarse fácilmente en GitHub Pages utilizando las GitHub Actions configuradas.

Simplemente haz push a la rama `main` o crea un tag, y el workflow de despliegue se ejecutará automáticamente.

Para despliegues manuales, puedes usar:

```bash
npm run deploy
```

Asegúrate de tener configuradas las credenciales correctas y permisos de escritura en el repositorio.
